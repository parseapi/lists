# Country codes

Every country and territory with its ISO 3166 alpha-2, alpha-3, and numeric codes, name and native name, capital, continent and region, demonym, official languages, currency, TLD, calling code, flag emoji, population, and area. JSON and CSV.

Source: ISO 3166 and official reference data. Refreshed monthly.

Generated from GET /country/{code}. Live lookups: [parseapi.com/country](https://parseapi.com/country).
